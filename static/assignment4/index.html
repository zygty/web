项目总览

这份展示不是把两个页面简单并排，而是把它们放回同一个研究语境中：一个负责支撑研究过程，另一个负责呈现轨迹数据与交互系统。

Research Workflow

Hermes Research Workbench

这是一个面向学术研究的工作台。它把文献检索、来源证据问答、综述整理和论文写作支持集中到同一个界面中。

  • 左侧文献库负责搜索、筛选与主题整理。
  • 中部论文视图负责展示选中文献的结构化信息。
  • 右侧工作区负责 grounded answer、综述和写作草稿。
Interactive System

航空地图系统

这是一个面向 ADS-B 轨迹数据的交互式地图系统。它把空间轨迹、时间变化和未来预测整合到一个可以直接讲解的界面里。

  • 地图负责展示航班轨迹、当前位置与覆盖范围。
  • 时间轴负责回放、暂停、拖动与调速。
  • 预测模块负责把未来轨迹叠加回地图界面。

Part 1 · 学术网站

第一部分展示的是一个研究工作流平台。重点不在单一页面样式，而在它如何围绕论文、证据和写作任务组织出一套可用的研究工作台。

主界面

页面明确展示了 Literature Library、Selected Literature、Paper Snapshot、AI Research Assistant 和 Literature Review 等模块。

写作工作流

右侧区域延伸到 draft title、draft topic、draft focus、导出 BibTeX / APA 等环节，体现出从阅读到写作的连续工作流。

Audience View

这个网站在展示什么

对观众来说，它展示的是“研究资料如何被组织、证据如何被调用、综述如何被构建、草稿如何被生成”。

它不是普通的论文列表，而是一张把阅读、整理、问答、综述和写作串起来的研究工作台。

从界面结构上看，左侧负责找资料，中部负责理解单篇论文，右侧负责把资料转化成答案、综述与写作输出。
文献管理

Literature Library

支持按 title、author、DOI、tag 等维度检索，让论文集合成为可持续使用的研究资产。

结构化阅读

Selected Literature

把标题、年份、标签、chunk 数和论文快照放在同一视图内，便于快速理解研究类型与方法结构。

来源证据

AI Research Assistant

强调 grounded answer，回答建立在召回的 source chunks 上，而不是脱离文献来源的自由生成。

综述支持

Literature Review

围绕 tags 和 paper limit 构建综述上下文，把分散文献整合为可直接写进报告的综述段落。

写作辅助

Writing Workflow

把研究主题、标题和焦点整理为写作输入，使页面从“阅读工具”延伸为“研究写作工具”。

导入导出

Import / Export

从导入 PDF 到导出 BibTeX、APA 和 workflow pack，表达的是一条完整的研究工作链条。

Part 2 · 航空地图系统

第二部分展示的是一个围绕 ADS-B 轨迹数据构建的交互式地图。它的重点不是“有一张地图”，而是地图如何把轨迹、时间与预测组织成完整的展示系统。

轨迹总览

多个样本航班在地图上同时出现，观众可以直接感知飞行方向、覆盖区域和空间分布，而不是只看离散表格。

System View

这个系统在展示什么

对观众来说，它展示的是一个把轨迹可视化、时间轴回放、状态监控和轨迹预测整合在一起的航空数据界面。

空间轨迹负责“看见航班怎么飞”，时间轴负责“看见它什么时候这样飞”，预测模块负责“看见它接下来可能怎么飞”。

因此，这一部分既是地图展示，也是一个可解释、可讲解、可继续扩展的数据系统。
Module 01

轨迹数据层

每个轨迹点都包含经纬度、高度、速度、航向和时间戳，这些字段共同决定了地图上的轨迹形状和时间变化。

Module 02

地图与时间交互

时间轴与播放控制让轨迹展示具有过程感，观众可以观察空域状态如何随着时间推进而变化。

Module 03

预测模块

对于选中的航班，系统会叠加未来若干步预测结果，使地图从历史回看延伸到未来估计。

Module 04

状态面板

活跃航班数、时间窗口、轨迹点数与控制按钮共同构成解释入口，让观众不用读代码也能理解界面含义。

可视化

动态轨迹展示

历史轨迹以折线方式绘制，当前位置被突出显示，更容易比较飞行方向与空域分布。

回放

时间轴控制

支持拖动、播放、暂停和调速，使一段轨迹数据变成可回放的时空叙事。

预测

未来轨迹叠加

预测结果直接回到地图界面中，让观众可以直观看到历史轨迹与未来估计之间的关系。

监控

状态解释区

同步展示航班数、轨迹点数和时间范围，使页面更像完整系统，而不只是孤立的可视化图片。

多底图

不同地理语境

深色、地形和卫星等底图切换让同一批轨迹数据可以在不同展示语境中被观看。

扩展性

后续分析基础

这套界面为实时数据流、热力图、机场分析和异常检测等后续扩展预留了清晰空间。

未来轨迹展示方式

预测模块把未来轨迹叠加到历史轨迹之上，使“已经发生什么”和“接下来可能发生什么”能够在同一地图视图中直接比较。

Why It Matters

为什么这一部分很适合展示

相比纯文本或表格，地图能以最直观的方式呈现飞行方向、航班聚集、时间变化和模型预测结果，因此非常适合课程展示和项目汇报。

  • 能看见空间分布，而不只是数据值。
  • 能回看时序过程，而不只是静态结果。
  • 能叠加预测输出，而不只是展示历史。

两个项目之间的关系

一个偏研究准备，一个偏系统展示；一个强调文献与写作，一个强调轨迹与交互。它们共同构成了围绕航空研究主题展开的项目组合。

Project Role

学术网站

负责组织论文、调用证据、生成综述和支持写作，更接近研究工作台的角色。

Project Role

航空地图

负责展示轨迹、回放时序和叠加预测，更接近可交互的轨迹系统与展示界面。

Combined Value

放在同一份报告中的意义

两者从研究支持与系统呈现两个方向，共同说明航空主题可以如何被组织、解释和展示。

Closing Note

一句话总结

这份展示页分成两部分：第一部分是面向学术研究流程的 Hermes Research Workbench，第二部分是面向 ADS-B 轨迹展示与预测的 航空地图系统。前者强调研究支持，后者强调系统展示，两者共同围绕航空研究主题展开。
