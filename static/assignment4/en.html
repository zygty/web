Project Overview

This showcase places both projects in the same research context: one supports the research workflow, while the other turns aviation data into an interactive visual system.

Research Workflow

Hermes Research Workbench

This is an academic research workspace. It brings literature search, source-grounded question answering, review writing, and draft support into a single interface.

  • The left panel manages search, filtering, and topic organization.
  • The middle panel focuses on the currently selected paper.
  • The right panel turns evidence into answers, reviews, and draft content.
Interactive System

Aviation Map System

This is an interactive ADS-B map. It combines spatial trajectories, time-based playback, and future prediction in one audience-friendly interface.

  • The map displays flight paths, current positions, and coverage.
  • The timeline enables playback, pause, scrubbing, and speed control.
  • The prediction layer places estimated future trajectories back on the map.

Structurally, the left side finds sources, the center interprets a paper, and the right side converts source material into answers and writing output.

Part 2 · Aviation Map System

The second part presents an interactive interface built around ADS-B trajectories. Its value lies in how it combines geometry, time, and prediction into one coherent system.

Real Website View

This is the actual aviation map interface from the website: the left column contains Data Status, Flight List, and Timeline Control, while the main map shows flight distribution on a dark basemap.

System View

What this system is really showing

For the audience, the map demonstrates how trajectory visualization, timeline playback, status monitoring, and path prediction can live in one aviation-facing interface.

Trajectories show where flights move, the timeline shows when they move, and prediction shows what might happen next.

The current main interface shows 100 cleaned flights and 10,912 trajectory points, so this section reflects the real website state rather than a simplified sample view.
Module 01

Trajectory Data Layer

Each point carries latitude, longitude, altitude, speed, heading, and timestamp, which together define the path and its temporal behavior.

Module 02

Map and Time Interaction

The timeline and playback controls give the system a sense of process, allowing the audience to watch the airspace evolve over time.

Module 03

Prediction Layer

For a selected flight, the system overlays several future steps, extending the interface from historical playback to forward estimation.

Module 04

Status Panel

Active flight count, time window, trajectory point count, and control buttons help viewers understand the interface without reading code.

Visualization

Dynamic Flight Paths

Historical paths are drawn as lines and current positions are emphasized, making direction and distribution easy to compare.

Playback

Timeline Control

Scrubbing, play, pause, and speed changes turn a set of trajectory points into a readable time-based narrative.

Prediction

Future Path Overlay

Predicted motion returns directly to the map, so viewers can compare history and estimated continuation in the same view.

Monitoring

Status Interpretation

Flight counts, point counts, and time bounds make the page feel like a system dashboard rather than a standalone visualization image.

Base Maps

Multiple Geographic Contexts

Dark, terrain, and satellite contexts let the same trajectory set be interpreted differently depending on the presentation goal.

Scalability

Foundation for Extension

The interface leaves clear room for live streams, heatmaps, airport analysis, and anomaly detection in later iterations.
